# Диаграмма состояний заявки

```mermaid
stateDiagram-v2
  [*] --> Черновик
  Черновик --> Подана: обязательные поля валидны
  Подана --> Проверка: запуск симуляции
  Проверка --> Одобрено: документы готовы и поток достаточен
  Проверка --> НужныДанные: документы не готовы
  Проверка --> Отказ: есть просрочка или расходы >= выручки
  Проверка --> АльтернативныеУсловия: поток положительный, но недостаточен
  Одобрено --> [*]
  НужныДанные --> [*]
  Отказ --> [*]
  АльтернативныеУсловия --> [*]
```

Фактическая реализация хранит исходный статус `Подана`, а затем результат проверки и итоговый статус. Для повторной проверки пользователь может изменить профиль и создать новую заявку.
