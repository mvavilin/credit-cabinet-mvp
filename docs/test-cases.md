# Тестовые сценарии

| ID | Входные условия | Ожидаемый результат |
|---|---|---|
| TC-01 | Выручка 1 500 000, расходы 1 100 000, платежи 50 000, документы готовы, просрочки нет | Одобрено (демо), если свободный поток >= 1.3 расчётного платежа |
| TC-02 | `docsReady = false` | Нужны данные |
| TC-03 | `overdue = true` | Отказ |
| TC-04 | `expenses >= revenue` | Отказ |
| TC-05 | Свободный поток положительный, но меньше 1.3 расчётного платежа | Альтернативные условия |
| TC-06 | ИНН не 10 или 12 цифр | Отправка заявки блокируется валидацией |
| TC-07 | Обновить страницу после создания заявки | Данные Zustand восстанавливаются из localStorage |
| TC-08 | Сброс демо | Профиль, чат и список заявок возвращаются к начальному состоянию |
